# 东粤化学 · 数字孪生平台展示

使用原生 HTML、CSS 和 JavaScript 构建的中文响应式项目展示网站，适配 GitHub Pages 子路径部署，无需构建步骤或第三方运行时依赖。

## 内容

- 宽幅三维厂区主视觉、9秒静音场景视频与四组可切换的平台界面
- 五阶段工艺路线与工艺流程、介质管网、二维 SCADA 三视角图文切换
- 四层技术架构，展开查看三维车间、数据中心、运维界面及数据接入关系
- 28 步、8 学时、4 阶段虚拟仿真教学建设方案
- 1080p 高清系统演示视频（约 5 分 16 秒）、6 个章节封面、按功能直接定位播放、原生控制和图片放大
- 9 张完整 1080p 视频截图，保留河海大学署名；教学章节补充 MR 虚实交互演示
- 移动导航、键盘操作、焦点管理和减少动画偏好支持
- 移动端及减少动画模式默认静帧；运镜离屏、页面隐藏或打开弹窗时暂停

## 本地预览

在此目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173`。

## GitHub Pages

以 `main` 分支根目录 `/` 为发布源。所有网页资源均使用相对路径，`.nojekyll` 关闭 Jekyll 处理。后续修改推送到 `main` 后，GitHub Pages 自动更新。

## 来源与边界

内容根据用户提供的《东粤化学数字孪生平台系统介绍》、功能演示 PPTX、演示视频及 2026 年度虚拟仿真实验教学项目申报材料整理。完整演示视频采用《东粤化学数字孪生系统-河海大学.mp4》的网页优化版本，保留 1920×1080 分辨率、30fps、原 AAC 音轨和全部内容；视频封面取自该文件第 20 秒完整画面。首页运镜沿用原演示片段。视频与图片为原项目演示素材的网页优化版本，素材中的产品界面不代表本网页接入了真实生产系统。

教学章节为建设方案；AI 内容为原材料中的应用方向与演示，不构成已验证的模型性能或生产收益声明。网站不控制真实设备、不接收生产数据、不收集访问者个人资料。原申报书、人员信息和内部分析文件未纳入此仓库。原素材权利归各自权利人所有。

## 画面与章节

新增静帧均从用户提供的高清源视频完整抽取，未裁切：设备联动 01:15、三维车间 01:30、报警记录 02:15、数据中心 02:45、工艺流程 03:20、介质管网 03:33、运维界面 03:45、智能分析 04:00、MR 交互 04:45。工艺视角中的二维 SCADA 静帧沿用功能演示 PPT 素材，并单独标注来源。
