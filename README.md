# 基于数字孪生的废塑料热解炼油智能工厂教学系统

面向数字孪生实验教学的中文浏览器应用。学生按“阅读原理与样例 → 修改配置 → 运行检查 → 根据反馈修正 → 记录与复盘”的路径，完成四阶段、28 项本地交互练习。课程教学安排为 32 学时，其中本实验 8 学时，每阶段 2 学时。面向智能科学与技术、人工智能、自动化及相关专业本科三、四年级学生，支持化学工程与工艺、环境工程等专业的跨学科实践。

在线访问：[教学应用](https://waido.github.io/dongyue-digital-twin/)。

使用原生 HTML、CSS、JavaScript，无构建步骤、第三方运行时或外部字体。练习在浏览器中计算，不需要登录或填写个人联系方式。

## 四阶段实验

| 阶段                | 任务  | 内容与反馈                                                                                                             |
| ------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------- |
| 需求分析与对象建模  | 1–7   | 配置需求与验收阈值、处理链路、资产层级、唯一编码、测点字典、坐标变换和对象映射；检查缺项、重复、循环、单位与空间误差。 |
| 数据接入与质量治理  | 8–14  | 离线连接配置、字段换算、采样与延迟比较、时间校准、数据清洗、历史回放计划和中断补传；返回逐条计算结果。                 |
| 三维映射与状态联动  | 15–21 | 用教学样本计算状态图示、双向定位目标、状态机轨迹、持续阈值事件、请求拒绝、事件定位与处置闭环。                         |
| AI 集成、验证与复盘 | 22–28 | 检查文档授权与版本、引用链、异常检测指标、配置比较与权限规则；汇总当前练习结果，填写修正过程和迁移条件。               |

输入会影响校验与计算结果。未满足条件时，页面显示具体原因及相关结果表；修改后可再次检查。目录、阶段统计和总进度反映当前输入对应的通过状态。前置配置发生变化后，第 27 项验收与第 28 项交付需要重新检查。

系统视频和截图作为教学参考，可按设备、数据、报警、AI 等章节观看，并支持查看大图。它们帮助理解实际系统画面，不替代本页的配置操作和结果检查。

## 保存、备份与报告

- **本机自动保存**：输入、最近一次检查结果、检查次数及实验记录保存在当前浏览器的 `localStorage` 中。换浏览器、换设备或清除站点数据不会自动同步；浏览器无法保存时，页面会提示使用备份。
- **JSON 进度备份**：“备份学习进度”导出可继续编辑的进度文件。导入会在确认后替换当前浏览器中的进度，并按当前练习规则重新核验检查结果。导入文件限 2 MB，面向同一版本教学应用。
- **Markdown 实验报告**：“导出实验报告”生成 `.md` 文件，包含当前配置、最近一次检查反馈、结果表、检查次数与学生记录。未完成和待复测项目也会如实列出，不会自动变成通过。

共用电脑上应使用各自的浏览器配置，并及时备份记录。应用没有云端账户、教师成绩库或跨设备自动同步。

## 教学样例与评价边界

设备标识、坐标、数值、阈值、文档片段和测试记录均为明确标注的教学样例。连接、请求和状态变化只在本地进行模拟或计算，不连接真实生产设备，不发送控制指令，不访问实际工业接口。样例参数用于理解软件逻辑，不作为工艺运行或安全参数。

三维相关练习检查绑定、坐标、状态和定位计算，不运行工业三维引擎。AI 相关练习检查引用、评测和可信控制，不调用生成式模型或生产 AI 服务。样例检查通过不代表真实系统性能、工业安全认证或完整教学平台验收。

页面的“通过”表示当前练习配置满足本题检查条件，用于学生自查。**正式课程评分由教师依据成果、证据与论证质量完成**，不把练习通过数换算为课程成绩。教学设计中的评分比例为：需求与架构 10%、建模与数据 25%、三维与联动 25%、AI 集成与验证 20%、报告与复盘 20%。总评 100 分；越权访问、生产侧写入或敏感信息外泄等关键安全测试未通过时，须修正并复测。

本应用不宣称项目已获立项、完成等级保护测评、联通共享平台接口，或获得已验证的工业 AI 准确率、能耗收益与并发性能。

## 文件与本地运行

| 文件                                 | 用途                                                       |
| ------------------------------------ | ---------------------------------------------------------- |
| `index.html`                         | 实验导学、操作区、进度与报告界面                           |
| `styles.css`                         | 响应式布局、字号、表单和反馈样式                           |
| `app.js`                             | 任务切换、配置采集、检查调用、本机保存、导入导出与媒体播放 |
| `lab-model.js`                       | 任务 1–7：需求、模型与映射                                 |
| `lab-data.js`                        | 任务 8–14：数据处理与链路                                  |
| `lab-state.js`                       | 任务 15–21：状态、事件与权限                               |
| `lab-evidence.js`                    | 任务 22–28：证据、评测、验收与交付                         |
| `course-outline.js`                  | 汇总稿中的 28 步课程要求、操作用时、评分条款与阶段成果     |
| `lab-visuals.js` / `lab-visuals.css` | 绑定状态卡和报警曲线                                       |
| `assets/`                            | 校徽、教学参考截图与演示视频                               |

在本目录启动静态服务器即可预览，例如：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。检查视频章节跳转时，应使用支持 HTTP Range 的静态服务器。不要仅用 `file://` 方式验证本机存储行为。

JavaScript 语法检查：

```sh
node --check app.js
node --check lab-model.js
node --check lab-data.js
node --check lab-state.js
node --check lab-evidence.js
```

实际验收还应覆盖：有效与无效配置、空输入、修改后的待复测状态、JSON 导入后重验、Markdown 导出、移动端表单与目录、键盘操作以及媒体关闭后的暂停与焦点恢复。

## 发布与来源

GitHub Pages 使用 `main` 分支根目录 `/`，`.nojekyll` 关闭 Jekyll。资源使用相对路径，适配仓库子路径。脚本和样式的版本参数用于刷新缓存，公开页面地址不附加版本参数。

课程内容以用户最新提供的《2026年度人工智能虚拟仿真实验教学项目申报书-汇总稿(1)》为准：基本情况表、3-2目标、3-3课时、3-4原理、3-5教学过程、3-6步骤、3-7结果和3-8学生要求。每步课程目标、建议用时、满分及评分条款与原表对应。28步建议操作用时合计220分钟，不等同于8学时；评分合计100分，步骤6–7归入三维映射维度，因此四阶段分值不可替代五类评价权重。原知识点清单第7条重复第1条，网站依据同节正文归纳为“设备状态机、事件规则与闭环”。征集通知与标准用于核对要求。平台介绍、功能演示 PPT 和系统视频提供工业场景参考。**原始申报书、PDF、PPT、私人联系方式及内部研究记录不作为公开下载发布**；公开内容为教学应用及所用媒体资产。

完整系统视频约 5 分 16 秒，保留原演示解说，1920×1080、30fps。该视频是系统操作参考，不等同于申报要求的限时简介或教学引导视频。截图中原有的时间、指标与数值属于录屏画面，不是本应用测得的生产结果。

校徽采用河海大学官方页面所载图样：[河海大学校徽官方来源](https://www.hhu.edu.cn/_t1503/2021/0326/c179a220941/page.psp)，用于页头、页脚与网站图标。素材权利归各自权利人所有。

字号层级参考 [NVIDIA Omniverse](https://www.nvidia.com/en-us/omniverse/) 与 [Siemens Digital Twin](https://www.siemens.com/en-gb/company/digital-twin/) 官方页面的可读性与信息层次。本应用桌面基准为主标题 **48 px**、章节标题 **36 px**、正文 **18 px**；窄屏正文基准为 **16 px**，标题随屏宽调整。使用系统无衬线字体及深色正文；这些数值是本应用的排版设置，不宣称两家参考网站使用完全相同的字号。未复制其品牌、代码或图片。

状态绑定练习配有四帧状态图示，持续报警练习配有样本曲线、阈值线和事件位置标记；两者均从本次检查输出生成，失败结果也可用于比较。

各任务的“课程要求与评分依据”保留完整课程目标，本页样例按其具体配置与检查范围练习。课程目标涉及的完整三维场景、服务集成和教学平台能力，不因列出目标即视为本站已经实现。对照配置与复测结论由学习者填写在实验记录中；应用保留当前配置和最近检查结果，不宣称自动保留完整版本历史。
