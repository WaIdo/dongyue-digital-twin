# 基于数字孪生的废塑料热解炼油智能工厂教学系统

中文响应式项目网站，以东粤化学数字孪生工厂为工程场景，介绍系统功能与实验教学设计。使用原生 HTML、CSS、JavaScript，无构建步骤、第三方运行时或外部字体。

## 页面内容

- 高清厂区全景与可暂停的 9 秒静音场景运镜
- 五阶段工艺路线，流程、管网、二维 SCADA 三个视角
- 设备定位、介质管网、趋势查询与异常分析，提供界面大图和相关视频
- 四阶段、8 学时、28 项实验任务，逐项展示操作、目标与验证方式
- 阶段交付成果、五类系统验收与考核比例
- MR 交互片段、四层技术架构和完整系统演示
- 1080p 视频原解说、六个章节封面、按章节定位播放

支持手机、平板和桌面布局，含键盘标签切换、弹窗焦点恢复、视频加载失败重试。手机、减少动画偏好及节省流量模式默认使用静态主图；运镜离屏、切换标签页或打开弹窗时暂停。完整演示只在用户播放时加载。

## 本地检查

在本目录启动静态服务器即可预览；检查视频章节跳转时应使用支持 HTTP Range 的服务器。JavaScript 语法检查：`node --check app.js`。

## 发布

GitHub Pages 使用 `main` 分支根目录 `/`，`.nojekyll` 关闭 Jekyll。资源采用相对路径，适配仓库子路径。公开地址为 https://waido.github.io/dongyue-digital-twin/ 。资源文件版本参数只用于缓存更新，页面地址不附加版本参数。

## 内容与素材

项目名、四阶段教学安排、28 步任务及评分来自用户提供的教学项目申报书；申报通知与标准用于核对教学要求，不作为项目已获立项或验收的证明。功能与架构依据平台介绍、功能演示 PPT 和系统视频。

教学部分属于实验教学设计。本站提供项目介绍、界面查看和视频播放，不运行实验平台、生产控制或自动评分，不宣称已完成教学系统上线、认证验收或 AI 效果验证。源文档、申请人员信息和内部审查记录未发布。

完整系统演示 `platform-demo-hd.mp4` 约 5 分 16 秒，保留原视频全部内容、1920×1080 分辨率、30fps 和 AAC 音轨。其时长不等同于申报所要求的简介或教学引导视频。

首页新主图来自高清源第 20 秒，运镜来自第 19–28 秒，裁切框均为 `(0, 0, 1920, 840)`，保留顶部河海大学署名；MR 静帧来自第 278 秒完整画面，画面内为校园三维场景。其他九张界面图保留完整 1920×1080 画幅，二维 SCADA 图来自功能演示 PPT。截图内文字、时间与数值为原始录屏内容。原素材权利归各自权利人所有。
